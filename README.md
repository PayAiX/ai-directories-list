- [ ] Write long description (150 words)

## Tips for Success

1. **Same email** - Use consistent email for tracking
2. **Save confirmations** - Screenshot each submission
3. **Product Hunt timing** - Launch Tuesday-Thursday, 12:01 AM PST
4. **Reddit rules** - Engage genuinely, don't spam
5. **Follow up** - Some directories take 1-7 days to approve
6. **Track results** - Note which directories drive traffic
